# oald-scripts

Various Python scripts to extract data files from the Oxford Advanced Learner's Dictionary (OALD).

## Scripts

### oald9-cd — OALD 9th Edition (Lingea/CD format)

Extracts assets from the Lingea container format used by OALD 9:

- Dictionary article records from `oup_en-dic.lld` (decoded XML-like markup)
- Images from `oup_en-dic.mbx`
- Audio from `oup_en-dic.wbx`

See [`oald9-cd/README.md`](oald9-cd/README.md) for full usage and options.

## Requirements

- Python 3.10 or newer
